- [Setup and authentication proof](docs/setup.md)

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
pnpm test
```

The current runnable UI is the authentication proof. Task planner, durable offline synchronization and notification delivery remain in subsequent stages; this repository is not release-ready.
