# App Design System

The app should have a **playful, modern, friendly and premium mobile design**, combining rounded components, bold typography, strong colors, generous spacing and simple hand-drawn illustrations.

## Colors

The color system should use:

- Primary dark blue: #1A5FCF	Buttons, links, key UI (white text contrast ~6:1)
- Secondary Dark blue: #12459A	Hover states, headers, dark sections
- Lime: #E9FF72	Accent / highlight
- Soft orange: #FFBC80	Accent / highlight
- Background: #FAF9F1	Page background
- Surface/cards: #FFFFFF	Cards, panels
- Main dark text: #14294D	Deep navy
- Muted text: #667389	Blue-tinted slate

The main relationship should be **dark primary + soft orange + playful secondary + warm neutrals**. Strong colors should be used selectively rather than covering every screen.

## Typography

Use a **rounded geometric sans-serif**.

Recommended:
- Headings: `Baloo2`
- UI/body: `Nunito Sans` (or Freedoka)

Typography should be bold and expressive:

- Hero: 48–64px, weight 800–900
- Screen title: 28–34px, weight 700–800
- Section title: 22–26px, weight 700–800
- Card title: 16–18px, weight 700
- Body: 15–17px, weight 400–500
- Caption: 12–14px, weight 500–600

Important numbers, statistics and values should be large enough to become visual elements themselves.

## Shapes

The interface should feel soft and rounded:

- Small radius: 12px
- Medium radius: 18px
- Cards: 20–24px
- Large containers: 28–32px
- Pills/chips: fully rounded (`999px`)

Avoid sharp corners.

## Spacing

Use an 8px-based spacing system:

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`

Use approximately `20–24px` horizontal screen padding and `16–24px` internal card padding.

## Cards

Cards should be a major part of the interface.

Use white cards over a warm off-white background with:

- 20–24px rounded corners
- Minimal or no shadows
- Optional subtle borders
- Generous whitespace
- Strong typography

Use colored feature cards occasionally to highlight important information or actions.

## Buttons & Chips

Buttons should be large, rounded and bold.

Chips and badges should be fully rounded, compact and colorful, using high-contrast combinations.

## Icons

Use simple rounded outline icons such as **Lucide** or **Phosphor Icons**.

Recommended:
- Size: 20–24px
- Stroke: 2–2.5px
- Rounded line caps

## Illustrations

Use simple **hand-drawn/doodle-style illustrations** as part of the brand identity.

They should:

- Use simple, slightly imperfect lines
- Use 1–2 colors
- Have little or no shading
- Feel playful and human
- Use exaggerated or friendly shapes

## Backgrounds

Avoid using pure white for entire screens.

Use a warm off-white as the main background, white for cards and strong brand colors for important sections.

This creates separation without relying on heavy shadows.

## Navigation

Use a clean bottom navigation with approximately 4–5 main destinations.

Inactive items should be muted. The active item should use the primary brand color and a stronger icon treatment.

## Overall Style

The app should feel:

**Playful + Friendly + Modern + Rounded + Editorial + Premium**

Most screens should remain visually clean and neutral, while personality should come from **bold typography, colorful feature cards, badges and custom illustrations**.
